# Data folder

The raw dataset is not stored in this repository.

* **Source:** Diabetes 130-US Hospitals for Years 1999-2008, UCI Machine Learning Repository, ID 296, https://doi.org/10.24432/C5230J
* **Automatic download:** the notebook downloads it with `ucimlrepo` (Internet must be on).
* **Offline:** download `diabetes_130_us_hospitals_raw.zip` from the Google Drive folder linked in the main README, unzip it here, and keep the file name `diabetes_130_us_hospitals_raw.csv`.
